# [KuuppaTab](https://kuuppatab.suklaasukkula.dev/)

This is a cool looking "new tab" page made for Stardance! ([View it in Stardance](https://stardance.hackclub.com/projects/55914))  
## Features:  
A random nebula themed background image from Nasa  
A search bar  
Bookmarks/Quick Links  
Nasa APOD section  
A funny red arrow for no reason  
Weather and a clock  
Caching to make the site load faster
A cool UI  
Hover animations
A customization menu that you can use to:  
Change your search engine  
Hide weather, Nasa APOD section and the funny red arrow  

You can set this as your New Tab page with [this](https://chromewebstore.google.com/detail/custom-new-tab-url/mmjbdbjnoablegbkcklggeknkfcjkjia) Chrome extension.  

This project was fun to make and it turned out really good.
